# Sets & HashSets & TreeSets

> Full Stack Web Development Bootcamp — Sprint 15, Day 2

![Java](https://img.shields.io/badge/Java-ED8B00?style=flat-square&logo=openjdk&logoColor=white)

## About

Explores Set-based collections in Java, focusing on HashSet and TreeSet implementations. This assignment covers uniqueness constraints, hashing mechanisms, and sorted collections.

## Key Concepts

- `Set` interface and uniqueness guarantees
- `HashSet` and hash-based storage
- `TreeSet` and natural ordering
- `hashCode()` and `equals()` contract
